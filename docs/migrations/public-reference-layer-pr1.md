# Public Reference Layer Repositioning — PR 1 Migration Note

## Change

The primary repository description changes from a generic AI capability control-plane workspace to a public, evidence-grounded delivery capability reference and governance repository for pinned downstream consumption.

## Preserved Compatibility

- Project identity remains `Lattice`, `lattice`, and `lat`.
- Existing Skill, Agent, registry, schema, harness, and routing paths remain in place.
- Existing runtime-native discovery and frontmatter remain unchanged.
- Feature Delivery Case remains the primary user-value and evidence boundary.
- Helixion, AegisFlow, Memexa, FlowGuard, OpenClaw, and DeliveryYield retain their boundaries.
- Existing capability-control-plane artifacts remain supported public implementation mechanisms.

## Changed Interpretation

- “Control plane” may describe an internal mechanism, not Lattice's primary purpose.
- “Generic” may mean public and company-agnostic, not purpose-free.
- Public conformance means a public contract passed named checks; it does not mean private adoption or manager value.
- Private repositories own real evidence, private extensions, adoption state, and manager-ready assets.

## Deferred Deterministic Changes

- PR 2: canonical capability manifest, role/status parity, lifecycle schemas, fixture correction, and projection CI.
- PR 3: downstream, extension, evidence, asset-pack, and manager schemas, validators, templates, and tests.
- PR 4: heterogeneous conformance runner, synthetic private consumer, golden outputs, complete CI, and private implementation guide.
